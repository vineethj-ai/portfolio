# Codebase Stack

## Languages
- TypeScript
- HTML / CSS

## Runtime & Frameworks
- Node.js (build environment)
- React 18
- Vite (bundler and dev server)

## Key Libraries
- **Three.js & React Three Fiber (@react-three/fiber, @react-three/drei):** 3D rendering and components.
- **Physics:** `@react-three/cannon` and `@react-three/rapier` for 3D physics.
- **Postprocessing:** `@react-three/postprocessing` for visual effects.
- **Animation:** `gsap` and `@gsap/react` for complex UI/scroll animations.
- **UI:** `react-icons`, `react-fast-marquee`.

## Configuration
- TypeScript config (`tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json`)
- ESLint (`eslint.config.js`)
- Vite config (`vite.config.ts`)
- Analytics (`@vercel/analytics`)
